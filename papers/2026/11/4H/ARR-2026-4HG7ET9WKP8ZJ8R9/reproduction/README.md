Sources and data tables for the 126-project cohort, action-key linkage and 118-action paired election-year comparison. The original protocols precede the data files; action-linkage/ contains the cross-register and calendar analyses. The collection programs run on Colab Linux. Some upstream URLs are mutable. The recorded digests identify the snapshots used, and the included derived ledgers allow the headline counts to be checked without contacting a service. Raw third-party papers and election pages are not redistributed.
