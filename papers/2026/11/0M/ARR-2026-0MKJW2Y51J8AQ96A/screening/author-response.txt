W1 — Expanded coordinates and useful-row normalization.
For a strong component j let s_o,s_e be its odd/even sum layers and put
x=(y1,y2,s_sigma-y1-y2), y in (Z/nZ)^2, sigma in {o,e}. Use the unitary
two-dimensional transform

  uhat_(j,sigma)(r,s) = n^(-1) sum_y u_(j,sigma)(y)
                              exp[-2*pi*i*(r*y1+s*y2)/n].

With the layer order and Fourier convention of Section7.1,
D(r,s)=[[3,-S],[-conj(S),3]], S=1+exp(2*pi*i*r/n)+exp(2*pi*i*s/n).
For (r,s) != (0,0), set z=(exp(2*pi*i*r/n),exp(2*pi*i*s/n),1)
and let P_W project onto span{(1,1,1),z} perpendicular. The operator in
Section7.2 can equivalently be specified on each component by

  (R0 u)hat_(j,sigma)(r,s)
      = H^(-1) sum_tau [D(r,s)^(-1)]_(sigma,tau)
                                      P_W uhat_(j,tau)(r,s),

and by zero at (r,s)=(0,0). This is a description of the already used R0,
not an added hypothesis or an inverse on the strong kernel. Indeed an
original character with k=(t+r,t+s,t) becomes
exp[2*pi*i*(r*y1+s*y2+t*s_sigma)/n]. The spatial projector is independent
of t and annihilates both original curl-adjoint normal vectors, which lie
in span{(1,1,1),z}. It therefore acts componentwise on actual coexact
fields; the matrix inversion comparison is only on non-diagonal fibres.

Reorder singleton rows as (o_j,e_j). Let J map component vectors v_j in
V=(1,1,1) perpendicular to row values v_j/sqrt(2) at both selected rows.
J is an isometry, and with N=n/2 the useful strong-kernel projector is

  P_E0 = J [ (I_N - 11*/N) tensor I_V ] J*.

The component matrix J* T R0 T* J is block diagonal. Its spatial trace in
block j is n^(-3)H^(-1)<p_j,G p_j>, p_j=(delta_o_j+delta_e_j)/sqrt(2).
The trace of P_V P_W is1. The omitted transverse-zero high vector has
opposite equal layer values and pairs to zero with p_j; the scalar
constant zero mode is already removed by G=D^dagger. Thus this block
trace is (g0+Re G(o_j,e_j))/(c*n^5). Multiplying by the diagonal
1-1/N of the component mean-zero projector and summing yields exactly
(22), with N-1 rather than2(N-1) multiplying the scalar lower bound.
The positive-weight rotation and its trace error remain as in Section7.3.
