# A metastable Hamming shell with exactly matched stationary marginals

Lluis Eriksson. AIRR working paper, ARR-2026-2B2W1WQ7DF9N5VW7, v1.

We construct finite Boolean noise Doob chains at correlation one half with exponentially small spectral gaps. The stationary densities have any fixed floor below one, converge exponentially to one in cubic mean, and match uniform coordinate marginals exactly through a positive fraction of the coordinates. An exponentially rare Hamming sphere retains the chain for exponentially many steps. A joint-type return estimate pays for a shell spike, and a positive scaling correction enforces exact matching. The normalized weighting densities have exponentially divergent cubic norms in the same family. The result applies along a progression of cube dimensions.
