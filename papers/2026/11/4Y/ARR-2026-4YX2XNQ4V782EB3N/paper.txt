Abstract
Motivated by the recent polynomial-time full structure recovery attack on Linearized Reed–
Solomon (LRS) codes from an arbitrary generator matrix by Astore, Borello, and Couvreur
(arXiv:2611.34835v1), we construct a machine-checked, zero-float finite-field verification and
algebraic cryptanalysis suite (LRS-STRUCT-RECOV-CERT-1.0). All 20 core theorems are proved
constructively in Lean 4.36.0 (zero sorry, zero Classical.choice, -DwarningAsError=true)
and paired with an AST-audited pure-integer finite-field Fpm = Fp[x]/(f (x)) engine (with Rabin
irreducibility verification and exact Gaussian elimination) emitting 16 SHA-256-indexed certifi-
cates (C01–C16) audited by 93 adversarial tests across F26 , F35 , F36 , F54 , F55 . Specifically, we
prove and certify: (i) the universal skew-norm cocycle Ni+j (a) = Ni(a)σi(Nj (a)) and Frobenius
shift identity a σ(Ni(a)) = Ni+1(a) (T01–T02, C14–C16); (ii) the exact closed-form Overbeck–
LRS Frobenius-sum bound dim Λt(C) ≤ min(n, ℓk + ℓ(t − ℓ + 1)) (t ≥ ℓ, k ≥ ℓ) and exact rank-
defect factorization ∆LRS(ℓ, k, t) = (t + 1 − ℓ)(k − ℓ) (T03–T08, C01–C09), proving onset strictly
at t = ℓ whenever k > ℓ and ℓ(k + 1) < n; (iii) exact invariance of every Frobenius-shift rank
profile under public-key scrambling Gpub = SGLRSP (S ∈ GLk(Fpm ), P ∈ ∏ r GLnr (Fp)); and
(iv) exact shortening-induced block collapse dim Λ1(Csh) ≤ k′ + 1 + δ < 2k′ whenever δ + 1 < k′,
triggering single-step distinguishers even for high-rate 2-block and 3-block LRS codes (T09–T10,
T18, T20, C10–C13).
1 Introduction
Linearized Reed–Solomon (LRS) codes [3] are optimal Maximum Sum-Rank Distance (MSRD)
codes attaining the sum-rank Singleton bound dsr = n − k + 1 (Lean T11), unifying classical Reed–
Solomon codes (ℓ = n, m = 1) and Gabidulin rank-metric codes (ℓ = 1, m ≥ n) [2]. Because
multi-block LRS codes (ℓ ≥ 2) initially resisted the classical single-step Overbeck structural attack
on Gabidulin codes [4], they were studied as post-quantum McEliece-type candidates until Astore,
Borello, and Couvreur [1] presented a general polynomial-time full structure recovery procedure from
an arbitrary generator matrix using Overbeck-type Frobenius-shift methods, matrix manipulations,
and shortening.
Here we construct LRS-STRUCT-RECOV-CERT-1.0 to formalize the algebraic backbone of
Overbeck–LRS distinguishers, shortening block collapse, and public-key scrambling invariance in
Lean 4.36.0 alongside an exact pure-integer Fpm linear-algebra certification engine.

3 Shortening-Induced Block Collapse and Rate-Regime Coverage
When high code rate (k ≥ n/ℓ − 1) causes untwisted Λℓ(C) to saturate at n (as in C09), shortening
s columns with 1 ≤ s < k < n strictly reduces the code rate (k − s)/(n − s) < k/n (Lean T10) and
collapses off-primary blocks to force a single-step (t = 1) Overbeck distinguisher:
Theorem 3.1 (Shortening Block-Collapse Criterion; Lean T09–T10, T18, T20). Suppose shortening
a set S of s coordinates (1 ≤ s < k < n) of an [n, k] ℓ-block LRS code leaves an [n′, k′] code
(n′ = n − s, k′ = k − s) with largest residual block B1 of size n′ 1 and remaining off-primary
coordinate count δ := ∑ℓ r=2 n′ r = n′ − n′ 1. Then
dim Λ1(Csh) ≤ min(n′ 1, k′ + 1) + δ ≤ k′ + 1 + δ, (5)

Proof. Because LRS evaluation on any s < k coordinates is surjective [3], every codeword c ∈ Csh
arises from a skew polynomial f = h ·σ MS ∈ Fqm [x; σ] of degree < k, where MS is the unique
monic minimal skew polynomial of degree s vanishing on S and deg h < k − s = k′. On the primary
block B1 (anchor a1, operator Da1 (u) = a1σ(u)), skew multiplication acts by operator composition:
(h ·σ MS )(Da1 )(β(1)) = h(Da1 )( ˜β(1)), where ˜β(1) := MS (Da1 )(β(1)) ∈ Fn′ 1 qm . Hence the restriction
Csh|B1 is a single-block Gabidulin-type code generated by Di a1 ( ˜β(1)) (0 ≤ i < k′). Since σ = a−1 1 Da1
shifts skew degree by +1 up to the single block-1 scalar a−1 1 , Λ1(Csh|B1 ) = Csh|B1 + (Csh|B1 )[1] has
dimension at most min(n′ 1, k′ +1). Projecting Λ1(Csh) ⊆ Fn′ 1 qm ⊕Fδ qm onto B1 has image Λ1(Csh|B1 ) and
kernel supported on the δ off-primary coordinates (dimension ≤ δ), giving (5) by rank–nullity.
Certificates C10–C13 verify Theorem 3.1 by exact finite-field shortening and Gaussian elimination
(Figure 2): shortening 4 coordinates of block 2 in F35 [10, 7] yields [6, 3] with δ = 1 < 2, dropping
dim Λ1 from 6 to 5 (C10); shortening all 5 coordinates of block 2 yields pure Gabidulin [5, 2] with
dim Λ1 = 3 < 4 (C11); shortening 4 coordinates in F36 [12, 8] yields [8, 4] with dim Λ1 = 7 < 8 (C12);
and shortening 9 coordinates across blocks 2–3 in a 3-block F55 [15, 12] LRS code yields [6, 3] with
residual blocks (5, 0, 1), dropping dim Λ1 from 6 to 5 (C13). Figure 3 maps the full rate coverage
combining direct primal Overbeck (R < 1/ℓ), dual Overbeck (R > 1 − 1/ℓ; Lean T13), and mid-rate
shortening.
