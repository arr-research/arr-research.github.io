# What would establish a lower cost per surviving mangrove? A finite-population audit of a restoration plan

Lluis Eriksson. Working paper v1.

Using an Indonesian restoration plan with 125,269 proposed seedlings, we derive a one-nursery census threshold and exact worst-case probabilities for prospective audits. In a specified 16-block register, a prespecified test based on 13 established positions in distinct random blocks has maximum false certification probability 0.048812, rounded. Concentrating all visits in a single random block raises the maximum to 0.750441. For product-weight selection of distinct blocks we derive the exact unequal-capacity bound and a sharp symmetric tolerance of 437 positions. A separate sensitivity shows how fixed costs affect a standardized budget comparison. These are planning calculations without field survival observations.
