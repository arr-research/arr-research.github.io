Even-q Double-Projective-Simplex Batch Codes, and
Deterministic Polynomial-Time Locality-2 Recovery

Abstract
Essayag and Zabokritskiy (arXiv:2611.34382v1) recently proved the functional batch
conjecture over every finite field Fq and dimension s ≥ 1, showing that the simplex code
Gq,s (all qs −1 nonzero vectors of Fs q ) is an optimal Tq,s-functional batch code with locality 2
for Tq,s = (qs + q − 2)/2, and proving that for odd q, 2N servers (N = (qs − 1)/(q − 1)) serve
every list of N + 1 requests—leaving open (i) whether F B(s, N + 1, q) = 2N holds for even
q ≥ 4, s ≥ 3 (Open Problem 3.13 of Kılıç–Ravagnani–Salizzoni), and (ii) polynomial-time
constructive recovery avoiding the non-constructive Balister–Győri–Schelp Pfaﬀian oracle.
We prove four new constructive theorems directly attacking both open problems: (1) an
Unconditional Characteristic-2 Two-Layer Theorem proving that for every even q ≥ 4, s ≥ 2,
hyperplane H (h = qs−1), and distinct layers Hα ∪ Hβ (2h servers), every list of h requests
outside H with arbitrary sum (zero or nonzero) is constructively served with locality 2 in
deterministic O(h2) time via M. Hall’s bijection and characteristic-2 translation invariance;
(2) an Even-q Double-Projective-Simplex Theorem proving that the fixed length-2N code
2 · Pq,s constructively serves with locality 2 (a) every list of N + 1 requests admitting a
balanced hyperplane flag |R ∩ Hj | = Nj + 1, and (b) for s = 3 and every even q ≥ 4, every
hyperplane-concentrated list (R ⊂ H0) of size N + 1 = q2 + q + 2 unconditionally (proved
via coloop-free q2-sublist extraction and projective scalar balancing); (3) a Deterministic
Polynomial-Time Recovery Theorem delivering locality-2 recovery with zero Balister–Győri–
Schelp oracle for all two-layer h-lists, all balanced-flag (N + 1)-lists (given the flag, or
unconditionally in O(q4) for s = 3), all hyperplane-concentrated (N + 1)-lists in F3 q , all
s = 2 lists, and hyperplane-avoiding full-Tq,s lists equipped with a characteristic-2 aﬀine
(h + 1, h)-block partition; and (4) an Exact Dimension-2 Constructive Capacity Theorem
proving tmax(Pq,2) = ⌊(q + 2)/2⌋ and tmax(2 · Pq,2) = q + 2 for all prime powers q ≥ 2. All 20
core algebraic, counting, and projective-recursion theorems (T01–T20) are formally verified
in Lean 4.36.0 (0 sorry, 0 grind, 0 Classical.choice, 0 custom axioms), paired with
an AST-pure zero-float verifier, 16 SHA-256 certificates, and 69 passing tests.
1 Introduction
Batch codes, introduced by Ishai, Kushilevitz, Ostrovsky, and Sahai [5], and their linear
functional generalizations studied by Zhang, Etzion, and Yaakobi [10], Hollmann et al. [4],
Yohananov–Yaakobi [8], Kılıç–Ravagnani–Salizzoni [6], and Oksner et al. [7], model distributed
storage systems storing s information symbols over Fq across n servers (columns of an s × n
generator matrix G). A matrix G is a t-functional batch code with locality 2 if every multiset
(list) of t nonzero request vectors r1, . . . , rt ∈ Fs q \ {0} can be served by pairwise disjoint re-
covery sets R1, . . . , Rt of columns of G, each of size 1 or 2, such that ri ∈ spanFq (Ri) for all
i. Let F B(s, t, q) denote the minimum length n of a t-functional batch code over Fq, and let
1



Ns(q) := (qs − 1)/(q − 1) denote the number of 1-dimensional subspaces (projective points) of
Fs q.
Essayag and Zabokritskiy [2] recently resolved the functional batch conjecture over every
finite field Fq and every dimension s ≥ 1: the (qs − 1)-column simplex code Gq,s serves every
list of Tq,s := (qs + q − 2)/2 requests with locality 2 (matching the counting ceiling), yielding
F B(s, mTq,s, q) = m(qs −1) for all m ≥ 1. For odd q, they proved a stronger statement: choosing
any two distinct nonzero vectors from each of the Ns(q) lines yields a 2Ns(q)-server code serving
every list of Ns(q) + 1 requests with locality 2, proving F B(s, Ns(q) + 1, q) = 2Ns(q) for odd
q (answering [6, Open Problem 3.13] for odd q). Two central open problems remain from [2,
Section 5]:
1. (Even-q Double Projective Simplex / Open Problem 3.13 of [6].) Does F B(s, Ns(q)+1, q) =
2Ns(q) hold for even q ≥ 4 and s ≥ 3?
2. (Deterministic Polynomial-Time Recovery.) For even q, the proof of [2] relies on the non-
constructive Pfaﬀian 2-adic valuation proof of the Balister–Győri–Schelp conjecture [1,
9]; which natural families of request lists admit explicit, deterministic polynomial-time
locality-2 recovery without invoking any Pfaﬀian existence oracle?
We prove four constructive theorems that directly advance both problems and yield explicit,
machine-verified recovery algorithms over Fs 2m .
2 Main Results
2.1 Theorem 1: Unconditional Characteristic-2 Two-Layer Recovery
Fix an even prime power q = 2m ≥ 4, dimension s ≥ 2, a hyperplane H ⊂ Fs q (|H| = h := qs−1),
and a vector e ∈ Fs q \ H. For each γ ∈ F∗ q , define the aﬀine layer Hγ := H + γe. Classical Hall-
based recovery over Fs 2 [3, 4] requires the h aﬀine request coordinates to sum to 0 in H. Our
first theorem eliminates the sum-zero restriction completely on any two distinct layers Hα ∪ Hβ
over every even field q ≥ 4.
Theorem 1 (Unconditional Characteristic-2 Two-Layer h-Request Theorem). Let q = 2m ≥ 4,
s ≥ 2, h = qs−1, and let α, β ∈ F∗ q be distinct nonzero scalars. Then the 2h-server pool Hα ∪ Hβ
constructively serves every list r1, . . . , rh ∈ Fs q \ H of h requests outside H—with arbitrary
aﬀine sum in H—with locality 2 in deterministic O(h2) time. Specifically:
• If the normalized aﬀine coordinates a1, . . . , ah ∈ H (where ri ∈ span(ai + e)) satisfy∑h
i=1 ai = 0, all h requests are recovered by h pairwise disjoint pairs (one server in Hα,
one in Hβ ).
• If S := ∑h i=1 ai ⁄= 0, then h − 1 requests are recovered by disjoint two-layer pairs and 1
request is recovered by a single server in Hα, leaving 1 server in Hβ unused.
Proof. Since q ≥ 4, choose any scalar c ∈ Fq \ {0, 1} and set c1 := 1 + c ∈ F∗ q . For every x, y ∈ H,
the two servers σ(x) := (α/c)x + αe ∈ Hα and σ′(y) := (β/c1)y + βe ∈ Hβ satisfy

2.2 Theorem 2: Even-q Double-Projective-Simplex Codes 2 · Pq,s
Let 2 · Pq,s denote the fixed s × 2Ns(q) matrix obtained by taking two distinct nonzero vectors
(say p and γp for fixed γ ∈ Fq \ {0, 1}) from each of the Ns(q) 1-dimensional subspaces of
Fs q. Because recovery depends only on the 1-dimensional spans of individual servers, 2 · Pq,s
is projectively scale-invariant: for every choice of hyperplane H ⊂ Fs q and basis vector e /∈ H,
rescaling each server individually within its own 1-dimensional subspace maps the 2qs−1 servers
of 2 · Pq,s lying outside H onto Hα ∪ Hβ for any distinct α, β ∈ F∗ q (in fact, even uniform line-by-
line scaling realizes Hα ∪Hγα with γα ⁄= α, which already suﬀices for Theorem 1) simultaneously
for every hyperplane H, while the remaining 2Ns−1(q) servers inside H realize 2 · Pq,s−1.
Theorem 2 (Even-q Double-Projective-Simplex Balanced-Flag and Hyperplane-Concentrated
Recovery). Let q = 2m ≥ 4 and s ≥ 3, and let 2·Pq,s be the fixed length-2Ns(q) double-projective-
simplex code.
1. (Balanced-Flag Lists in Arbitrary Dimension s ≥ 3.) Let R be any list of Ns(q)+1 nonzero
requests in Fs q equipped with a balanced flag of subspaces Fs q = Vs ⊃ Vs−1 ⊃ · · · ⊃ V2
(dim Vj = j) such that |R ∩ Vj | = Nj (q) + 1 for every j = s − 1, . . . , 2. Then, given the
balanced flag (or unconditionally at s = 3 by enumerating all q2 + q + 1 hyperplanes),
2 · Pq,s constructively serves R with locality 2 in deterministic polynomial time O(s · q2s−2).

2. (Unconditional Hyperplane-Concentrated Recovery in Dimension s = 3.) For s = 3 and
every even q ≥ 4, 2 · Pq,3 constructively serves every list R ⊂ H0 of N3(q) + 1 = q2 + q + 2
requests concentrated inside a single hyperplane H0 ∼= F2 q (including all-on-one-line worst-

Proof. Part 1: By the exact projective recursion Nj (q) = qj−1 + Nj−1(q) (proved for all q, j in
Lean T10–T11), |R ∩ (Vj \ Vj−1)| = (Nj (q) + 1) − (Nj−1(q) + 1) = qj−1 for each j = s, s − 1, . . . , 3.
By projective scale invariance, the 2qj−1 servers of 2 · Pq,s inside Vj \ Vj−1 realize two aﬀine
layers Hα ∪ Hβ of Vj relative to Vj−1 and serve the qj−1 requests in Vj \ Vj−1 unconditionally by
Theorem 1 (no sum constraint!). The remaining N2(q)+1 = q +2 requests in V2 ∼= F2 q are served
by the 2(q + 1) servers in V2 via Theorem 4 below. Notice also by double-counting incidences in
PG(s−1, q) (Lean T19) that for every list R of size Ns(q)+1, the average hyperplane intersection
is Ns(q)+1 Ns(q) Ns−1(q) ∈ (Ns−1(q), Ns−1(q) + 1), so there always exist hyperplanes with ≤ Ns−1(q)
and ≥ Ns−1(q) + 1 requests.
Part 2: Let R ⊂ H0 ∼= F2 q have |R| = q2 + q + 2 (h = q2). Group requests by projective
line in H0. We extract an h-sublist Rout ⊂ R containing no coloop (i.e., no line of H0 holds
exactly h − 1 elements of Rout): if some line L∗ has multiplicity ≥ h, take h copies from L∗;
otherwise every line has multiplicity ≤ h − 1, so taking at most h − 2 copies from the most
frequent line and filling the remaining ≥ 2 slots from other lines (possible since total remaining
requests outside L∗ is at least (q2 + q + 2) − (h − 1) = q + 3 ≥ 7) guarantees no line holds h − 1
elements of Rout.
We now assign nonzero scalars λ1, . . . , λh ∈ F∗ q such that ∑h i=1 λiri = 0 in H0:
• If all h elements of Rout lie on one line L∗, choose λi so all λiri equal a common generator
v ∈ L∗; since h = q2 is even in characteristic 2, hv = 0.
• Otherwise, pick two indices p0, p1 in Rout on distinct lines (forming a basis (v0, v1) of
H0 ∼= F2 q ). Because no line has multiplicity h − 1, the remaining h − 2 indices include
at least one vector not on span(v0) (or we can adjust two scalars over |F∗ q | = q − 1 ≥ 3
nonzero choices): for any fixed assignment to all but one element u of the remaining
h − 2, varying λu ∈ F∗ q moves the partial sum Srest through q − 1 ≥ 3 distinct points of
a line parallel to span(u). Since the union of the two coordinate axes span(v0) ∪ span(v1)
intersects any aﬀine line (not contained in an axis) in at most 2 points and q − 1 ≥ 3 > 2,
at least one choice of λu ∈ F∗ q (or adjusting a pair of distinct-line elements if all h − 2 sit
on axes) places Srest = av0 + bv1 with a ⁄= 0 and b ⁄= 0! Setting λp0 = a and λp1 = b yields∑h

Applying M. Hall’s theorem [3] to (λiri)h i=1 yields bijections (xi), (yi) of H0 with xi + yi =
λiri. Taking distinct layers Hα, Hβ (α ⁄= β ∈ F∗ q ), the two servers σi = xi + αe ∈ Hα and

(Lean T12), recovering all h = q2 requests of Rout using the 2q2 servers outside H0. The
remaining (q2 + q + 2) − q2 = q + 2 requests in R \ Rout ⊂ H0 are served by the 2(q + 1) servers
inside H0 via Theorem 4 (Fig. 2, certificates C06–C11).

2.4 Theorem 4: Exact Constructive Capacities in Dimension s = 2
Our final theorem gives the exact constructive capacities and tight counting barriers for both
the single projective simplex Pq,2 (length N = q + 1) and double projective simplex 2 · Pq,2
(length 2N = 2(q + 1)) over every prime power q ≥ 2 (serving as the base case for Theorem 2).
Theorem 4 (Exact Dimension-2 Constructive Capacities). For every prime power q ≥ 2:
1. The single projective-simplex code Pq,2 (N = q + 1 servers, 1 per line) has exact locality-2
functional batch capacity tmax(Pq,2) = ⌊(q + 2)/2⌋, and no larger list size can be served
even with arbitrary recovery set sizes.
2. The double projective-simplex code 2 · Pq,2 (2N = 2(q + 1) servers, 2 per line) has exact
locality-2 functional batch capacity tmax(2·Pq,2) = q +2, attaining F B(2, q +2, q) = 2(q +1)
constructively in O(q log q) time for all even and odd q.
Proof. Upper bounds: Consider t copies of a single request on line L, where nL of the n servers
lie on L. Any size-1 recovery set must use a server on L, so there are s1 ≤ nL size-1 recovery
sets. Each of the remaining t − s1 recovery sets has size at least 2 (whether or not it uses any
remaining server on L), consuming at least 2(t − s1) of the remaining n − s1 servers; hence
2(t − s1) ≤ n − s1, giving 2t ≤ n + s1 ≤ n + nL (Lean T01). At (n, nL) = (q + 1, 1) this gives
t ≤ ⌊(q + 2)/2⌋ (Lean T04); at (n, nL) = (2q + 2, 2) it gives t ≤ q + 2. Moreover, for any t-
functional batch code of length n in F2 q , summing 2t ≤ n + nL over all N = q + 1 projective lines
(using ∑ L nL = n) yields 2t(q + 1) ≤ (q + 2)n (Lean T02); setting t = q + 2 gives n ≥ 2(q + 1)
(Lean T03), proving the code-independent converse F B(2, q + 2, q) ≥ 2(q + 1).
Constructive attainment for Pq,2: Given t ≤ ⌊(q + 2)/2⌋ requests hitting d ≥ 1 distinct lines,
assign the unique server on each of those d lines as a singleton recovery to one request on that
line. Because d + 2(t − d) = 2t − d ≤ 2t − 1 ≤ q + 1 (Lean T15), at least 2(t − d) servers remain
on pairwise distinct lines; since any two distinct lines in F2 q span F2 q , arbitrarily pairing these
2(t − d) servers recovers all remaining t − d requests.
Constructive attainment for 2 · Pq,2: Given t = q + 2 requests, let c1 be the number of
lines requested once and c2 the number requested at least twice. Satisfy up to 2 copies on
every requested line using singletons, yielding s1 = c1 + 2c2 singleton recoveries. By pigeonhole
on q + 1 lines, c2 = 0 would force c1 = q + 2 > q + 1 (impossible), hence c2 ≥ 1 and s1 ≥ 2

then u = 2 is impossible, because u = 2 forces s1 = 2q ≥ q + 2 (for all q ≥ 2), contradicting
r ≥ 1. Therefore u ≥ max(2r, 3), so every line holds at most mmax ≤ 2 ≤ u − r unused servers
(checking both r = 1 =⇒ u − r ≥ 2 and r ≥ 2 =⇒ u − r ≥ r ≥ 2, including the odd boundary
