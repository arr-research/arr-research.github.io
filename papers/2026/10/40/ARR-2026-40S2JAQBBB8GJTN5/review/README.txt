The canonical published manuscript is ../paper.pdf relative to review/. The files in initial-packet are a superseded prepublication draft supplied only to audit the revision history; they are not the public v1 manuscript. initial/ holds the unmodified first review of that draft. revised-packet contains the exact final review input, whose PDFs match the canonical published manuscript. The current exact-version review is directly in review/. Both stages use the same reviewer context for the final corrections; no certified blind review is claimed. To reproduce revision_audit.py, copy both verifiers from revised-packet to a writable OUTPUT/verification directory and run them there, then pass initial-packet, revised-packet and OUTPUT as its three arguments. The public root includes construction-review/verify_averaged_extension.py, deliberately excluded from the review-only packets.
