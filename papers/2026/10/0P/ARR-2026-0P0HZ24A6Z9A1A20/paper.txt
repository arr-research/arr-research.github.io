Small exact values for Green’s Problem 37 (m(N, 3) for N ≤ 17,
bounds beyond) and a reproduction of the table for Problem 27
Lluis Eriksson
22 October 2026
Abstract
Let m(N, k) be the least size of a ﬁnite set of integers containing, for every d = 1, . . . , N,
a k-term arithmetic progression of common diﬀerence d (Problem 37 in Green’s list; k = 3
unless stated). I could not ﬁnd a table of its values in the literature. With CP-SAT in Z I
obtain m(N, 3) = 3, 4, 5, 6, 7, 8, 8, 8, 9, 10, 11, 11, 12, 12, 12, 13, 13 for N = 1, . . . ,17; for N ≤ 10
this is also supported by DRUP proofs of SAT instances whose reduction to a ﬁnite window
is proved in the note. For N ≤ 27 I give veriﬁed witnesses (upper bounds) and, inside the
window [0, 2N], DRUP-certiﬁed lower bounds up to N = 23. The window is not harmless:
for N = 15the true value is 12 but no 12-element set ﬁts in [0, 30] (the optimum has diameter
35), so for N > 17 the lower bounds are only window bounds. I also give a few values for
k = 4. For Problem 27 ( m(p) in Z/pZ) I recomputed m(p) for primes p ≤ 31; these values were
already published, so this is a reproduction, not new. Everything is computational, produced
by AI agents, without human review or formal veriﬁcation of the pipeline.
1 The problems
Problem 37. Green’s 100 open problems [1] asks for the smallest subset of N containing, for
each d = 1, . . . , N, an arithmetic progression of length k and common diﬀerence d. Green writes
Fk(N) for it, conjectures Fk(N) ≫ k N1−ck with ck → 0, and notes (with Ruzsa [ 2]) that this
is equivalent to the arithmetic Kakeya conjecture of Katz and Tao. The formal-conjectures ﬁle
GreensOpenProblems/37.lean [3] deﬁnes m(N, k) = min{|A|: A ⊂ N ﬁnite, ∀1 ≤ d ≤ N ∃a :
a, a+ d, . . . , a+ (k − 1)d ∈ A}and records only the trivial bound m(N, k) ≤ kN + 1. Translating
A shows that it makes no diﬀerence whether A ⊂ N or A ⊂ Z.
Problem 27. For a prime p, m(p) is the least |A|, A ⊂ Z/pZ, |A| ≥ 2, such that every
element of A + A has at least two representations a + b as an unordered pair (the deﬁnition
HasNoUniqueRepresentation in [ 3]; a = b allowed). It was studied by Straus and Bedert [ 4].

3 From Z to a ﬁnite search
Lemma 1. Let A ⊂ Z be ﬁnite and suppose that for each 1 ≤ d ≤ N it contains a k-term AP
of diﬀerence d. Then there is B with |B|= |A|, min B = 0, with the same property and with all
gaps between consecutive elements ≤ N; in particular diam B ≤ N(|B| −1).
Proof. Translate so that min A = 0. Let a < bbe consecutive elements of A with b − a > N.
A k-AP P ⊂ A of diﬀerence d ≤ N cannot have a term ≤ a and a term ≥ b: two consecutive
terms y < y+ d would satisfy y ≤ a < b≤ y + d, so d ≥ b − a > N. Hence each such P lies in
L = A ∩ (−∞ , a] or in R = A ∩ [b, ∞ ). Replace A by L ∪ (R − (b − a − 1)): the elements of R
are moved to the right of a, no two elements merge, translating R preserves all APs inside R, so
the new set has the same size and still contains all required APs. Each step reduces the number
of large gaps.
Consequently the SAT instance “ x0 = 1; for each d ≤ N some yd,a with yd,a → xa ∧ xa+d ∧
xa+2d; at most s of the xa (0 ≤ a ≤ W); gap clauses” with W = N(s − 1) is satisﬁable iﬀ some
set of at most s integers works. This is the Z-certiﬁcate. With W = 2N and no gap clauses the
same formula decides the window problem (W-certiﬁcate); W = 2N is only a restriction, not a
reduction. The gap clauses are xa ∧ ta+N+1 → ∨a+N
j=a+1 xj with ta ↔ xa ∨ ta+1. Lemma 1 is the
only reduction used for the Z results.
4 Methods and veriﬁcation
CP-SAT in Z. For each (N, s): integers 0 =x0 < · · ·< xs−1 with gaps in [1, N+ 1], a Boolean
for every k-subset of indices and every d forcing consecutive diﬀerences = d, and one clause per d;
a reﬂection symmetry break. Sizes are increased until feasible. OR-Tools 9.15, 8 workers, status
INFEASIBLE/OPTIMAL as reported by the solver; no independent certiﬁcate exists for these
results, except those marked Z in Table 1. In addition CaDiCaL on the Z-instance for N = 13,
s = 11(W = 130, 360 s) also reported UNSAT.
Window SAT and proofs. Windows were solved with CaDiCaL (PySAT); each UNSAT
instance (size m − 1) was re-solved with Glucose 4 logging DRUP, and the proof was checked by
rup.exe, a forward RUP checker in Go with two watched literals (the one written for the Gowers–
Long note; deletions ignored). Negative controls on the N = 8 proof: it is rejected against the
satisﬁable size- 8 formula (at lemma 6), cut in half (no empty clause), with a false ﬁrst lemma ¬x0
prepended, and the bare empty clause is rejected. The checker is not drat-trim nor a veriﬁed
checker; encoder and checker are trusted. Altogether 29 DRUP proofs of the k = 3 instances
were accepted (21 window, 8 Z); the longest has 175187 lemmas ( N = 22, W = 44, s = 15;
25242143 bytes; checked in 1522 s). SHA-256 of every CNF and proof are in g37/cert37.jsonl;
proof ﬁles for small N are in the supplement, larger ones can be regenerated with cert37.py.

Witnesses. All witnesses are checked by verify_witnesses.py, a naive loop sharing no code

small cases also by decide +kernel. The ﬁle compiled with exit code 0. No Lean statement
connects these checkers to the formal-conjectures deﬁnitions.
Problem 27 encoding. Variables xa and yab (a ≤ b, yab → xa ∧ xb); for each pair, xa ∧ xb →∨ycd over the other pairs with the same sum; 0, 1 ∈ A (an aﬃne map x ↦→ux + v preserves
the property, and any A with |A| ≥ 2 can be mapped to contain 0, 1); cardinality ≤ k by a
sequential counter. PySAT’s CaDiCaL prints a harmless message found falsified original
clause (also seen in the Green 22 note); results were checked by witnesses and proofs.
5 What is not veriﬁed
(i) For N > 17 no lower bound in Z is proved beyond monotonicity; UB there is only an upper
bound and, as N = 15shows, may not be sharp. (ii) The Z values for N >10 rest on CP-SAT’s
reported status (cross-checked once by CaDiCaL for N = 13). (iii) The RUP checker is home-
made. (iv) No theorem links the encodings or Lean checkers to the formal-conjectures statements.
(v) No asymptotic information: these small values say nothing about N1−ck . (vi) The literature
search was limited (Green’s list, Green–Ruzsa, two OEIS searches, a few web searches); I found
no earlier values for m(N, 3), but this is not a priority claim. (vii) No human review.
