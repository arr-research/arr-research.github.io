\begin{abstract}
Let $m(N,k)$ be the least size of a finite set of integers containing, for every $d=1,\dots,N$, a $k$-term arithmetic progression of common difference $d$ (Problem~37 in Green's list; $k=3$ unless stated). I could not find a table of its values in the literature. With CP-SAT in $\mathbb Z$ I obtain $m(N,3)=3,4,5,6,7,8,8,8,9,10,11,11,12,12,12,13,13$ for $N=1,\dots,17$; for $N\le 10$ this is also supported by DRUP proofs of SAT instances whose reduction to a finite window is proved in the note. For $N\le 27$ I give verified witnesses (upper bounds) and, inside the window $[0,2N]$, DRUP-certified lower bounds up to $N=23$. The window is \emph{not} harmless: for $N=15$ the true value is $12$ but no 12-element set fits in $[0,30]$ (the optimum has diameter $35$), so for $N>17$ the lower bounds are only window bounds. I also give a few values for $k=4$. For Problem~27 ($m(p)$ in $\mathbb Z/p\mathbb Z$) I recomputed $m(p)$ for primes $p\le 31$; these values were already published, so this is a reproduction, not new. Everything is computational, produced by AI agents, without human review or formal verification of the pipeline.
\end{abstract}

\section{The problems}
\paragraph{Problem 37.} Green's \emph{100 open problems} \cite{green100} asks for the smallest subset of $\mathbb N$ containing, for each $d=1,\dots,N$, an arithmetic progression of length $k$ and common difference $d$. Green writes $F_k(N)$ for it, conjectures $F_k(N)\gg_k N^{1-c_k}$ with $c_k\to0$, and notes (with Ruzsa \cite{gr}) that this is equivalent to the arithmetic Kakeya conjecture of Katz and Tao. The formal-conjectures file \texttt{GreensOpenProblems/37.lean} \cite{fc} defines $m(N,k)=\min\{|A|: A\subset\mathbb N \text{ finite},\ \forall\, 1\le d\le N\ \exists\, a:\ a,a+d,\dots,a+(k-1)d\in A\}$ and records only the trivial bound $m(N,k)\le kN+1$. Translating $A$ shows that it makes no difference whether $A\subset\mathbb N$ or $A\subset\mathbb Z$.

\paragraph{Problem 27.} For a prime $p$, $m(p)$ is the least $|A|$, $A\subset\mathbb Z/p\mathbb Z$, $|A|\ge2$, such that every element of $A+A$ has at least two representations $a+b$ as an \emph{unordered} pair (the definition \texttt{HasNoUniqueRepresentation} in \cite{fc}; $a=b$ allowed). It was studied by Straus and Bedert \cite{bedert}.

\paragraph{The window is not harmless.} For $N\le14$ and $N=16,17$ the CP-SAT value in $\mathbb Z$ equals $m_{[0,2N]}(N)$, but for $N=15$ it is $12<13=m_{[0,2N]}(15)$: the set $\{0,5,10,12,13,14,17,20,24,26,28,35\}$ (diameter $35>2N$) works. \section{From $\mathbb Z$ to a finite search}
\begin{lemma}\label{lem:gap}
Let $A\subset\mathbb Z$ be finite and suppose that for each $1\le d\le N$ it contains a $k$-term AP of difference $d$. Then there is $B$ with $|B|=|A|$, $\min B=0$, with the same property and with all gaps between consecutive elements $\le N$; in particular $\operatorname{diam}B\le N(|B|-1)$.
\end{lemma}
\begin{proof}
Translate so that $\min A=0$. Let $a<b$ be consecutive elements of $A$ with $b-a>N$. A $k$-AP $P\subset A$ of difference $d\le N$ cannot have a term $\le a$ and a term $\ge b$: two consecutive terms $y<y+d$ would satisfy $y\le a<b\le y+d$, so $d\ge b-a>N$. Hence each such $P$ lies in $L=A\cap(-\infty,a]$ or in $R=A\cap[b,\infty)$. Replace $A$ by $L\cup(R-(b-a-1))$: the elements of $R$ are moved to the right of $a$, no two elements merge, translating $R$ preserves all APs inside $R$, so the new set has the same size and still contains all required APs. Each step reduces the number of large gaps.
\end{proof}
Consequently the SAT instance ``$x_0=1$; for each $d\le N$ some $y_{d,a}$ with $y_{d,a}\to x_a\wedge x_{a+d}\wedge x_{a+2d}$; at most $s$ of the $x_a$ ($0\le a\le W$); gap clauses'' with $W=N(s-1)$ is satisfiable iff some set of at most $s$ integers works. This is the Z-certificate. With $W=2N$ and no gap clauses the same formula decides the window problem (W-certificate); $W=2N$ is only a restriction, not a reduction. The gap clauses are $x_a\wedge t_{a+N+1}\to\bigvee_{j=a+1}^{a+N}x_j$ with $t_a\leftrightarrow x_a\vee t_{a+1}$. Lemma~\ref{lem:gap} is the only reduction used for the Z results.

\section{Methods and verification}
\paragraph{CP-SAT in $\mathbb Z$.} For each $(N,s)$: integers $0=x_0<\dots<x_{s-1}$ with gaps in $[1,N+1]$, a Boolean for every $k$-subset of indices and every $d$ forcing consecutive differences $=d$, and one clause per $d$; a reflection symmetry break. Sizes are increased until feasible. OR-Tools 9.15, 8 workers, status \texttt{INFEASIBLE}/\texttt{OPTIMAL} as reported by the solver; \textbf{no independent certificate exists for these results}, except those marked Z in Table~\ref{tab:k3}. In addition CaDiCaL on the Z-instance for $N=13$, $s=11$ ($W=130$, 360 s) also reported UNSAT.

\paragraph{Window SAT and proofs.} Windows were solved with CaDiCaL (PySAT); each UNSAT instance (size $m-1$) was re-solved with Glucose~4 logging DRUP, and the proof was checked by \texttt{rup.exe}, a forward RUP checker in Go with two watched literals (the one written for the Gowers--Long note; deletions ignored). Negative controls on the $N=8$ proof: it is rejected against the satisfiable size-$8$ formula (at lemma 6), cut in half (no empty clause), with a false first lemma $\neg x_0$ prepended, and the bare empty clause is rejected. The checker is \textbf{not} drat-trim nor a verified checker; encoder and checker are trusted. Altogether 29 DRUP proofs of the $k=3$ instances were accepted (21 window, 8 Z); the longest has 175187 lemmas ($N=22$, $W=44$, $s=15$; 25242143 bytes; checked in 1522 s). SHA-256 of every CNF and proof are in \texttt{g37/cert37.jsonl}; proof files for small $N$ are in the supplement, larger ones can be regenerated with \texttt{cert37.py}. Proofs for the Z-instances $N=11,12$, for the window instance $N=24$ and for $m(29),m(31)$ in Problem~27 were produced but the checker runs were interrupted when I stopped; they are not counted anywhere.

\paragraph{Witnesses.} All witnesses are checked by \texttt{verify\_witnesses.py}, a naive loop sharing no code with the solvers, and by Lean~4 (core, no Mathlib): \texttt{lean/Green2737.lean} defines Boolean checkers \texttt{covers} and \texttt{noUnique} and proves each witness by \texttt{native\_decide} (trusts the compiler); small cases also by \texttt{decide +kernel}. The file compiled with exit code~0. No Lean statement connects these checkers to the formal-conjectures definitions.

\paragraph{Problem 27 encoding.} Variables $x_a$ and $y_{ab}$ ($a\le b$, $y_{ab}\to x_a\wedge x_b$); for each pair, $x_a\wedge x_b\to\bigvee y_{cd}$ over the other pairs with the same sum; $0,1\in A$ (an affine map $x\mapsto ux+v$ preserves the property, and any $A$ with $|A|\ge2$ can be mapped to contain $0,1$); cardinality $\le k$ by a sequential counter. PySAT's CaDiCaL prints a harmless message \texttt{found falsified original clause} (also seen in the Green~22 note); results were checked by witnesses and proofs.

\section{What is not verified}
(i) For $N>17$ no lower bound in $\mathbb Z$ is proved beyond monotonicity; UB there is only an upper bound and, as $N=15$ shows, may not be sharp. (ii) The Z values for $N>10$ rest on CP-SAT's reported status (cross-checked once by CaDiCaL for $N=13$). (iii) The RUP checker is home-made. (iv) No theorem links the encodings or Lean checkers to the formal-conjectures statements. (v) No asymptotic information: these small values say nothing about $N^{1-c_k}$. (vi) The literature search was limited (Green's list, Green--Ruzsa, two OEIS searches, a few web searches); I found no earlier values for $m(N,3)$, but this is not a priority claim. (vii) No human review.
