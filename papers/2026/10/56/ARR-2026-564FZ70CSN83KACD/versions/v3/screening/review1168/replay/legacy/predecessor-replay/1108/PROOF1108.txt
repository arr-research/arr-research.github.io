1. Remove zero output rows, allow other zero entries.
Write K(y|0)=a_y,K(y|1)=b_y, a_y,b_y>=0, sum a=sum b=1. Delete y with a_y=b_y=0; these are identically zero output blocks for every input and carry no divergence. For faithful cq input blocks, A,B in the1092/1093 whitening proof remain strictly positive. Every remaining pencil a_y A+b_y B is strictly positive: at least one coefficient is positive. Consequently b_y I+(a_y-b_y)X is invertible for every eigenvalue0<x<1 of X. The entire positive-resolvent/quadratic/SLD proof is unchanged. Strict positivity of both entries of each row was sufficient but unnecessary.

Define c(K)=sup_{0<x<1} x(1-x) sum_active_y (a_y-b_y)^2/[b_y+(a_y-b_y)x]. Use SUPREMUM, not an assertion of a unique interior maximum. Endpoint-only optima or constant functions occur. The scalar faithful local lower still applies: each active output probability is positive for each fixed interior x, so Taylor and f''(1)>0 apply. Take local tangent limit first, then sup over x. No singular boundary inverse is evaluated. For nonfaithful states with finite positive denominator, compress to common reference support and use the SAME faithful regularization plus lower semicontinuity/joint convexity described in audit1093; do not admit infinity/infinity or zero/zero.

This establishes, subject to checking this small extension, the same global complete equal-reference coefficient for each normalized nonaffine operator-convex Petz divergence and SLD/minchi for every finite binary-input classical channel. It does not extend to arbitrary divergences, unequal reference marginals or three input columns. The two-output formula (sqrt(a(1-b))-sqrt(b(1-a)))^2 continues to all0<=a,b<=1. For b=0,a>0, F(x)=a(1-x)/(1-a*x), sup a as x->0; for a=b=0 the channel is constant and coefficient0. Endpoint1 gives coefficient1 as expected. Do not reuse the strict-concavity or interior-attainment clauses of audit1093 on these boundaries.

2. Direct exclusion-channel binary restriction proof, avoiding reliance on extension1.
For n>=3, K(y|i)=(1-delta_yi)/(n-1). Restrict the INPUT to any two distinct labels i,j. Take arbitrary cq states with blocks rho_i,rho_j and sigma_i,sigma_j, each pair summing to the SAME r. Output y=i is rho_j/(n-1), y=j is rho_i/(n-1); for every y distinct from i,j, output is r/(n-1) in BOTH hypotheses. Petz divergences on positive unnormalized blocks are homogeneous under common scaling. Summing over orthogonal output blocks therefore gives EXACTLY
 D_f(Krho||Ksigma)=D_f(rho||sigma)/(n-1),
because f(1)=0 kills every identical r block. This is valid for every admissible faithful cq pair, not only a tangent or an optimal pair. SLD metric/minchi follow from the same block homogeneity. For general quantum inputs use input dephasing DPI; cq inputs give matching equality. Thus the complete coefficient of every two-input restriction is exactly1/(n-1), including this zero-entry endpoint. This is an erasure-type decomposition, not a novel erasure theorem.
