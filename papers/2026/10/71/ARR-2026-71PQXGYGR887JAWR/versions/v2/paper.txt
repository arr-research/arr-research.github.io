Abstract
Weestablishanextensionoftheentropy-budgetminimaxlawforoscillatorresetchannels
to a thermal attenuator in the transmitted branch. The necessary and sufficient regime for
the full loss curves is environment occupationn= o(E), whereE is the input energy, with
the channel fixed throughout each code. The full Shannon and fixed super-Shannon curves
have the same bounded absolute loss as for an identity or pure-loss signal, relative to the
thermal channel’s own entanglement-assisted benchmark. The key argument combines a
bounded Choi form, a largest-eigenvalue bound for near-capacity inputs, output pinching,
and Audenaert’s established telescopic relative-entropy inequality. It avoids a continuity
error proportional tologE. Explicit input/output truncation errors give the matching
common-code bound without an energy constraint on the reset. A separate extension
treats unknown fixed signal parameters in a known temperature envelope, with the same
sharp sublinear criterion. Necessity follows from a strictly positive, dimension-independent
gap below the binary flag entropy whenever the signal mutual information is bounded.
The gap combines established purification/Gram, fidelity and relative-entropy inequalities;
it is transferred to a common energy-constrained code for arbitrary fixed resets. The result
does not determine the critical-regime minimax curve. Working-argument audits support
these arguments; they are not a full assessment of this exact PDF, a priority certificate or
editorial acceptance.
