Finite diagnostic controls only; not proofs, codes, Gaussian optimization or formal verification.
Dependencies: Python 3, mpmath, numpy.
Run in a writable copy: python check612.py; python check614.py.
612: 90 scalar cases at180 decimal digits, including linear-noise stress cases.
614:72 generic noncommuting finite matrices testing the fixed-reference pinching and normalized-comparator identities.
The Gaussian infinite Choi form and asymptotic capacity law are established analytically, not by these controls.
Original programs and expected results are unchanged from frozen612/614.
