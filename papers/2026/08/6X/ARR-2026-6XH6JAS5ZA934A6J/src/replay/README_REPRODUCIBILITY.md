# Bounded replay

From the record root, install `numpy` and `scipy`, then run:

```powershell
powershell -ExecutionPolicy Bypass -File src/replay/replay_all.ps1
```

The replay is single-process and normally completes in a few seconds. It checks finite representation identities, exceptional cumulants, hypergeometric normalization, and bounded scalar diagnostics. It does not prove the general analytic theorems.
