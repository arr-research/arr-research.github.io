# Matroidal Bayes Bounds for General Quantum Process Discrimination

This directory contains the manuscript, exact regression fixtures, figure
source, and deterministic release builder for the paper.

## Main result

For positive process hypotheses with arbitrary priors, the vector of
correct-label probabilities generated by every admissible general tester lies
in the independence polytope of the Rado matroid of the process support
subspaces.  The Bayes success probability is therefore bounded by the prior
weight of a maximum-weight independent transversal.  The theorem covers mixed
process operators and any access architecture represented by the stated
physical deterministic tester cone.

A second theorem makes the certificate stable under full-rank noise.  Any
positive low-rank core may be used in place of the exact process operator; the
Bayes ceiling then receives only the prior-weighted worst-case discarded
tester mass.  A valid process admixture of weight `eta` therefore weakens the
bound by at most `eta`.  The manuscript also gives explicit mixed-support
pseudocode through linear matroid intersection and an arithmetic complexity
bound.

The exact qubit examples include a trine phase flat plus an orthogonal Pauli
coloop.  At priors `(0.30, 0.30, 0.30, 0.10)`, the Rado ceiling and the attained
general-tester optimum are `0.70`, while the total-span top-prior relaxation is
`0.90`.  All four decision effects are nonzero.

## Lightweight replay

```powershell
python verify_canonical_tester_compression.py
python package_release.py --check
```

The exact verifier uses SymPy rational/algebraic arithmetic and no numerical
tolerance.  It includes a genuinely singular Moore--Penrose compression, a
mixed rank-two Rado fixture, and a full-rank-noise spectral-tail fixture.  It
is a regression suite for finite instances; the manuscript contains the
general proofs.  The same `--check` command works inside an extracted release
ZIP: it verifies the bundled source PDF, canonical PDF, payload, and manifest;
when the outer ZIP is present it additionally verifies deterministic archive
bytes.

## Scope

- The deterministic normalization must belong to the physical tester/comb
  cone of the chosen access model.
- The result is an upper bound, not a claim that parallel, sequential, and
  indefinite-order optima coincide.
- Support data alone need not determine the mixed-state optimum.
- The spectral-tail extension requires a chosen positive core and a valid
  bound on its discarded tester mass; it does not optimize the core.
- The Hilbert-function comparison is rank-one and uses ordinary repeated
  access to the same unitary channel.
- Rado--Edmonds theory, canonical tester compression, and the symmetric trine
  measurement are credited as established ingredients.
