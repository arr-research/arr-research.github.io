# Independent reproducibility audit: the dimension-eight parametric family

Date: 2026-08-24 (Europe/Stockholm)  
Status: **EXACT TWO-ROUTE REPLAY PASS**

## Audited statement

For

```text
lambda_t = (4-3t,t,t,t,-1,-1,-1,-1),   0 <= t <= 1,
```

let `kappa_8(lambda_t)` be the minimum inverse self-commutator cost and let
`kappa_8^(<=4)(lambda_t)` be the same Horn program restricted to squared
singular-value rank at most four. The two exact routes certify

```text
                       { 10-7t,  0 <= t <= 1/2,
kappa_8(lambda_t) =    {
                       {  9-5t,  1/2 <= t <= 1,

kappa_8^(<=4)(lambda_t) = 10-6t,

kappa_8^(<=4)(lambda_t) - kappa_8(lambda_t) = min(t,1-t).
```

Consequently the minimum rank on the norm-optimal face is five for
`0<t<1` and four at `t=0,1`. This conclusion is only about the displayed
family. It does **not** prove that dimension eight is the first dimension in
which super-inertial optimal rank occurs.

### Route B: direct Littlewood--Richardson tableaux

`verify_parametric_family_lr.py` imports neither the recursive generator nor
Route A. It:

1. converts each subset to its Horn partition;
2. decides positivity of each Littlewood--Richardson coefficient by direct
   semistandard tableau enumeration with the lattice-word condition;
3. regenerates all specialized Horn rows from those positive coefficients;
4. represents spectra, primals, right-hand sides and residuals as pairs
   `(constant, t-coefficient)` over `fractions.Fraction`;
5. checks every residual at both endpoints of its closed interval;
6. verifies the sparse dual rows, weights, combined objective coefficients
   and affine right-hand sides from scratch;
7. stores every named affine residual and both exact endpoint values.

## Exact affine primals

Route B independently checks these squared-singular-value spectra, with the
eighth conventional zero suppressed:

```text
p_low(t) =
  (8-6t, 6-6t, 4-4t, 2, 2t, 0, 0),       0 <= t <= 1/2;

p_high(t) =
  (8-6t, 4-2t, 2, 2, 2-2t, 0, 0),        1/2 <= t <= 1;

p_face(t) =
  (8-6t, 6-4t, 4-2t, 2, 0, 0, 0),        0 <= t <= 1.
```

They are ordered and nonnegative on the claimed intervals. Their half-sums
are respectively `10-7t`, `9-5t` and `10-6t`. The first two vectors coincide
exactly at `t=1/2`:

```text
p_low(1/2)=p_high(1/2)=(5,3,2,2,1,0,0).
```

Every one of the 8,759 residuals is affine on the relevant interval. An
affine function nonnegative at both endpoints is nonnegative throughout the
closed interval, so the endpoint checks are a symbolic coverage proof and
not a parameter grid.

## Rank and endpoint audit

- At `t=0`, the spectrum has inertia `(1,4,3)` and `p_low(0)` has rank four;
  the rank-face gap is zero.
- For `0<t<1`, the target has inertia `(4,4,0)`, the displayed unrestricted
  optimum has rank five, and the strictly positive rank-face gap excludes
  every factor of rank at most four from the global optimal face.
- At `t=1`, the spectrum is sign-paired, `p_high(1)` has rank four, and the
  rank-face gap again vanishes.
- The maximum certified separation in this normalized family is `1/2`, at
  `t=1/2`.

## Scope and limitations

This audit certifies a continuous one-parameter family by exact Horn/LR
arithmetic. It does not:

- prove that dimension eight is the smallest failing dimension;
- exclude a dimension-six or dimension-seven counterexample outside previous
  finite searches;
- classify all dimension-eight spectra or all norm-minimizing matrices;
- construct entries of a realizing factor `C` (existence is supplied by the
  classical Horn theorem after spectral feasibility);
- certify novelty, priority, peer review or a proof-assistant formalization.
