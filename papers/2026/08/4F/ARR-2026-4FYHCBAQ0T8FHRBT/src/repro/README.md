# Replays

Run the command python .\run_all_replays.py from this directory.

verify_dimension_three_sharpness.py checks exact combinatorics, exact
rational ranks of finite Lefschetz-map fixtures, and direct Tjurina
quotients over two large prime fields.

verify_global_fixtures.py checks exact simplex-evaluation ranks and the
integer decompositions used for the complete surface spectrum.

These are finite fixtures. They do not prove the universal local theorem,
contact determinacy, Bertini incidence, or existence claims.
