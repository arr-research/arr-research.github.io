# Strictly Scalable Exterior Decoders for Quantum Lists

- ARR identifier: `ARR-2026-3H0ZKWJMH18MH9FX`
- Version: `v1`
- Record type: `research_paper`
- Author: Lluis Eriksson
- Status: accepted founder-pilot deposit
- Canonical source: `paper.pdf`

The paper evaluates the exact learning width of strictly scalable full-spark
pure-state ray ensembles, constructs a weighted exterior-power decoder, and
derives exact fixed-probe and divisor-branch Weyl list frontiers together with
the complete consecutive rank-two Bayes curve.

The record separates technical preservation from scientific certification.
The author is also ARR's founder-editor; no independent peer review,
frontier-model screening, formal proof, novelty certification, or scientific
validation is claimed.
