# Exact replay scripts

Run from this directory with Python 3:

```text
python verify_list_matroid_union.py
python verify_exact_qubit_separation.py
python verify_laminar_channel_phase.py
python verify_multitime_ueb.py
```

All scripts use the Python standard library only.  They verify finite exact
fixtures and formula identities and do not substitute for the manuscript's
general proofs.
