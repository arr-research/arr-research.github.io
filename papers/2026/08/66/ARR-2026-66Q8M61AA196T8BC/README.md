# ARR-2026-66Q8M61AA196T8BC v1

This founder-owned ARR pilot candidate preserves Lluis Eriksson's research
paper, *Mixed-Jet Rank Floors for Point-Span Higher Osculating Absorption*.

It is a separate successor to ARR-2026-19BXX42GM38K6VZ3. The earlier record
studies first-order tangent absorption and a Gauss-fiber alternative; this
record assumes explicit order-`s` osculating absorption and proves a
characteristic-free arbitrary-order mixed-jet hierarchy. It does not supersede
the earlier paper.
